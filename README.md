# BANGTIENDO

Kho lưu trữ file dùng chung giữa laptop và PC.

Cách dùng:

```bash
git pull      # lấy file mới nhất trước khi làm việc
git add .
git commit -m "Cập nhật file"
git push      # đẩy lên để máy kia lấy về
```
